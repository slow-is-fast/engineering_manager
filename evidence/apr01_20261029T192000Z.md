# APR-01 演练证据：人工审批闸门（2026-10-29T19:20+08:00）

**控制**：APR-01（**P0**）· **规则**：GOV-06 人工最终责任 / GOV-15 审批绑定与失效 / GOV-17 不得自批 / SEC-009 R3 不得因 AI Reviewer PASS 自动放行
**用例**：T-APR-01 · **实现**：控制面 `executor/approval.py`（提交 `0e1aea5…`），数据面同步并 bump pin

## 1 · 闸门语义

审批不是一句"同意"，而是一个**有界对象**：绑定 `task_id + risk + scope + policy_hash + commit_sha(如适用) + expires_at`。任一要素漂移、过期或吊销 → 失效；R3 必须有**人类**审批，AI Reviewer 的 PASS 只能作参考。

| 注入 | 期望 | 实际 |
|---|---|---|
| 未知审批 ID | REJECT | ✅ `unknown_approval` |

## 3 · 状态与边界

APR-01：`documented/configured/tested = true`，`verified = false`。

**诚实边界**（写入模块 docstring）：本模块验证"**审批记录与当前请求是否一致**"，它**不证明审批人本人的意愿**——那是身份服务的职责（与 ATT-01 同类声明）。因此 APR-01 记为 tested（逻辑验证）。
