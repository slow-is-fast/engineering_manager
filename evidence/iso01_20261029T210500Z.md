# ISO-01 演练证据：项目/租户数据边界守卫（2026-10-29T21:05+08:00）

**控制**：ISO-01（**P0**）· **规则**：v1.1.1 §4 记忆生命周期与项目数据隔离 · **应答**：AUD-016
**用例**：T-ISO-01 · **实现**：控制面 `executor/scope.py`（提交 `2e60be6…`），数据面同步并 bump pin

## 1 · 守卫语义

1. Run 必须绑定 `project_id` / `repository_id` / `tenant_id`，**未绑定不得访问任何数据**；
2. 访问目标的 project / tenant 必须与绑定值**完全一致**；
3. **通配范围（`*`）拒绝**——这是越权常见手法；
4. 仓库可不绑定（同项目多仓库场景），但若提供则必须一致；
5. **未分类数据按最高敏感级别处理**（不因"没标"而放宽）；
6. 每次拒绝写 `boundary_violation` 审计事件，可告警、可复现。

## 3 · 诚实边界（写入模块 docstring）

本模块是**进程内的边界判定**。真正的租户隔离还需要存储层权限、独立租户存储与网络策略（AUD-016 的完整范围）——**不得据本模块宣称"已实现租户隔离"**。因此 ISO-01 记为 `tested`（逻辑验证）。
