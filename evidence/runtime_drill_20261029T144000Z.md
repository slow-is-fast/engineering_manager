> `403: Upgrade to GitHub Pro or make this repository public to enable this feature.`

规则集（rulesets）同样 403。**免费账户的私有仓库不提供服务器端强制能力**，这意味着：

| 治理层 | 当前状态 |
|---|---|
| 检测层（静态校验、负向用例） | ✅ 已建成并运行 |

| 审批层（Owner review） | ⚠️ 流程存在，但无技术强制，纯自律 |
