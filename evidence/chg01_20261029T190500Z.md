# CHG-01 演练证据：策略变更影响评估与活动 Run 处置（2026-10-29T19:05+08:00）

**控制**：CHG-01（P1）· **规则**：GOV-16（P0，MUST NOT「禁止悄悄热替换策略造成证据不一致」）· **用例**：T-CHG-01 · **应答**：AUD-017

## 1 · 实现（控制面 `executor/change.py`，提交 `0cf3cba…`）

1. **活动 Run 注册表**：run_id / task_id / 启动时绑定的 policy_hash / owner / 状态。
2. **受影响集合**：发布变更时计算"启动策略 ≠ 新策略"的活动 Run（已是新策略的 Run 不计入）。
3. **逐个处置**：四选一 `continue` / `pause` / `reauthorize` / `terminate`，**缺省即 REJECT**（失败关闭）。
4. **重大安全热修复（severe=True）禁止 `continue`**——GOV-16 的核心。
5. **`reauthorize` 必须带与新策略一致的审批证明**，且审批人不得是 Agent 主体或该 Run 的 owner（不得自批）。
6. 全部写审计流（`change.rejected` / `run.disposition` / `change.published`）。
