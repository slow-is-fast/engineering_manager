# EVD-01 / EVD-02 演练证据：防篡改审计流（2026-10-29T19:30+08:00）

**控制**：EVD-01（证据完整性，P0）、EVD-02（审计不可用失败关闭，P0）
**规则**：GOV-03 证据优先 / GOV-04 失败关闭 / GOV-05 全过程追溯 / SEC-008 审计不可由 Agent 停用
**实现**：控制面 `executor/audit.py` 升级（提交 `1eb4d3b…`），数据面同步并 bump pin

## 1 · 改造内容

| 能力 | 说明 |
|---|---|
| **哈希链** | 每条事件带 `seq` / `prev_hash` / `hash`；`hash = sha256(规范 JSON(事件除 hash 外))`，并链入前一条哈希（创世值 `0*64`） |
| **`verify()`** | 逐条重算哈希、校验 `prev_hash` 连续性与 `seq` 单调性 → 返回 `(ok, errors)` |
| **失败关闭** | `read(strict=True)` / `ensure_available()` 在文件**缺失、损坏、链校验失败**时抛 `AuditUnavailable`——不再返回空列表假装"没有事件" |

## 2 · T-EVD-01 结果

| 注入 | 期望 | 实际 |
|---|---|---|
| 原始链（正向对照） | verify OK | ✅ `ok=True` |
| 篡改中间一条内容（`x=2` → `x=999`） | 检出 | ✅ `hash mismatch (content altered)` |
| 删除中间一条 | 检出 | ✅ `prev_hash mismatch (chain broken)` + seq 错位 |
| 两条重排 | 检出 | ✅ 链断裂 |

## 3 · T-EVD-02 结果

| 注入 | 期望 | 实际 |
|---|---|---|
| 审计文件缺失 + `read(strict=True)` | 抛异常 | ✅ `AuditUnavailable` |
| 审计文件缺失 + `ensure_available()` | 抛异常 | ✅ `AuditUnavailable` |
| 正常链（正向对照） | 通过 | ✅ `ensure_available()=True` |
| 文件损坏（截断 JSON）+ strict | 抛异常 | ✅ `AuditUnavailable`；`verify()` 报 `corrupt json` |

## 4 · 诚实边界（写入模块 docstring）

哈希链让篡改**可检测**，但**不等于不可篡改**——写入权限仍在持有者手里。真正的防篡改需要**独立审计存储与权限分离**（GOV-14/VD-01 与 AUD-014 的职责）。因此 EVD-01/02 记为 `tested`（逻辑验证），不越界宣称"证据不可篡改"。
