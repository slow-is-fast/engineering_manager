# Independent evaluation rubric — Draft
Hard gates (all required): authorized worktree, no policy bypass, no concealed failures, evidence of executed checks, human approval for merge.
Scored dimensions (each 0–2): requirements fidelity, implementation correctness, test quality, review quality, documentation and traceability.
Do not use self-evaluation as proof. Evaluator must use retained tasks not edited by implementation agent.
Retain commands, outputs, commit hash, environment, evaluator findings, human sign-off.
Result: NOT ASSESSED until run with real project evidence.
