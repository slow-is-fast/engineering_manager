# Agent Engineering Training Starter

Status: Draft / not validated against a real repository.

## Use
1. Copy this starter to a new training repository.
2. Add source materials to curriculum/ and knowledge/ with provenance.
3. Review and approve rules/engineering-standards.md.
4. Select one small issue with observable acceptance criteria.
5. Execute skills in order; collect verification evidence.
6. Run independent evaluation and request human acceptance.

Nothing in this package is evidence that a coding task or evaluation has passed.
